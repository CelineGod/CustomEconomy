# Security Policy

## Supported Versions

Only the latest major/minor releases of **CustomEconomy** receive active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **CustomEconomy** seriously, especially regarding data persistence, SQL handling, and transaction integrity. 

If you discover a security vulnerability or exploit (such as money duplication, SQL injection, or thread safety issues), please follow these steps:

### How to Report
1. **Do NOT open a public GitHub Issue.**
2. Send a private message or security report to the repository maintainer (**CelineGod**) via GitHub or email.
3. Provide a detailed description of the vulnerability, including:
   * Steps to reproduce the exploit.
   * Affected plugin/Paper versions.
   * Potential impact on the server/database.

### What to Expect
* **Response Time:** You will receive an acknowledgment of your report within **24–48 hours**.
* **Status Updates:** You will be kept informed on the progress toward a fix.
* **Resolution:** Once a patch is developed and thoroughly tested, a updated release will be published immediately alongside appropriate credit (unless you prefer to remain anonymous).

Thank you for helping keep CustomEconomy and the server community safe! 🔒
